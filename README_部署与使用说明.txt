公基刷题网页版 PWA V1.1 功能增强版

【本版重点新增】
1. 继续上次刷题
2. 未做题专项
3. 随机10题 / 20题 / 50题
4. 题库搜索
5. A核心223掌握进度
6. 错题按模块统计
7. 模块正确率排行
8. 模拟考试错题复盘
9. PWA安装入口（浏览器支持时）
10. 学习数据备份包含刷题进度

【原有功能继续保留】
- 完整700题
- A核心223
- B高频157
- B扩展119
- C补充201
- 8大模块专项
- 单选 / 多选 / 判断
- 判断题 A正确 / B错误
- 上一题 / 下一题 / 答题卡
- 错题本 / 收藏夹
- 模拟考试（自定义题量和时长）
- 学习统计
- 可编辑考试日期
- 每日目标
- 深色模式
- 数据导出 / 导入
- PWA离线缓存

【推荐部署】
优先使用 GitHub + Vercel。
具体步骤见：
GitHub与Vercel自动部署指南.txt

【当前公开网址】
如果你已经把 V1.0 部署到 Vercel，当前网址仍可继续使用：
https://gongji.vercel.app

将 Vercel 项目连接到 GitHub 后，更新 main 分支即可自动更新该网址。

【隐私】
本项目不需要登录。
学习数据默认仅保存在使用者自己的浏览器 localStorage 中。
不上传手机号、定位、通讯录或答题记录。
