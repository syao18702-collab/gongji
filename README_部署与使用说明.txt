公基刷题网页版 PWA V1.1 功能增强版

【本版重点新增】
1. 继续上次刷题
2. 未做题专项
3. 随机10题 / 20题 / 50题
4. 题库搜索
5. A核心223掌握进度
6. 错题按模块统计
7. 模块正确率排行
8. 模拟考试错题复盘
9. PWA安装入口（浏览器支持时）
10. 学习数据备份包含刷题进度

【原有功能继续保留】
- 完整700题
- A核心223
- B高频157
- B扩展119
- C补充201
- 8大模块专项
- 单选 / 多选 / 判断
- 判断题 A正确 / B错误
- 上一题 / 下一题 / 答题卡
- 错题本 / 收藏夹
- 模拟考试（自定义题量和时长）
- 学习统计
- 可编辑考试日期
- 每日目标
- 深色模式
- 数据导出 / 导入
- PWA离线缓存

【推荐部署】
优先使用 GitHub + Vercel。
具体步骤见：
GitHub与Vercel自动部署指南.txt

【当前公开网址】
如果你已经把 V1.0 部署到 Vercel，当前网址仍可继续使用：
https://gongji.vercel.app

将 Vercel 项目连接到 GitHub 后，更新 main 分支即可自动更新该网址。

【隐私】
本项目不需要登录。
学习数据默认仅保存在使用者自己的浏览器 localStorage 中。
不上传手机号、定位、通讯录或答题记录。


【V1.2 本次交互优化】
1. 首页“我的学习”中：
   - 已做题目：可点击进入已做题目列表
   - 错题本：可点击进入
   - 收藏题目：可点击进入
   - 累计正确率：保持仅展示，不设置点击
2. 所有普通刷题页支持左右滑动：
   - 左划：下一题
   - 右划：上一题
3. 模拟考试同样支持左右滑动切题。
4. A核心、B高频、完整700题、模块专项、未做题、错题本、收藏夹等稳定板块：
   - 自动记录上次题号
   - 再次进入时自动续接，不再从第1题开始
5. 随机10/20/50题仍按“每次重新随机”的逻辑运行，不强制续接旧随机题组。
6. Service Worker 缓存版本已更新为 V1.2，便于部署后客户端刷新资源。


【V1.3 本次修复】
1. 修复首页“模拟考试”入口点击无反应：
   - 新增全局 goMock() 跳转入口
   - 保持原模拟考试功能、题量和时长设置不变
2. 补全题库四层入口：
   - A核心223
   - B高频157
   - B扩展119
   - C补充201
3. B扩展、C补充同步支持断点续刷、上一题/下一题、左右滑动、答题卡、错题记录、收藏。
4. 首页和“刷题中心”的按层级刷题均补全扩展层和补充层。
5. Service Worker 缓存版本升级到 V1.3。
